# Balance Fix v3

Исправлен баг: игрок мог выбрать Игорька `1 IN 1`, из-за этого `effectiveClickBase()` становился маленьким, а динамические цены боксов/Card Pack резко дешевели.

## Что изменено

### Цены магазина

Цены боксов и Card Pack теперь считаются не от текущего выбранного Игорька, а от лучшего открытого Игорька игрока:

```js
bestOwnedSkinPower()
stableIncomePower()
```

То есть игрок больше не может поставить слабый скин, чтобы удешевить магазин.

### Снижение сломанной статистики

Добавлен `balanceVersion: 3`.

При первом запуске после обновления игра проверяет старое сохранение. Если у игрока явно взломанная/разогнанная статистика, например десятки тысяч кубков, она снижается до нормального диапазона.

### Серверная защита

В API `/api/player` добавлена нормализация:

- слишком большие кубки снижаются;
- слишком большой уровень снижается;
- монеты ограничиваются;
- при обновлении записи больше не используется `GREATEST`, чтобы старые сломанные значения можно было понизить.

### Leaderboard

`/api/leaderboard` показывает нормализованные значения через SQL `LEAST(...)`, поэтому даже старые записи с 100k кубков не должны висеть в топе.

## Что надо сделать на Vercel

После загрузки обновления сделать Redeploy.

Игроки со старой сломанной статистикой будут урезаны:

1. В клиентском сохранении при входе.
2. В базе после следующего сохранения игрока.
3. В лидерборде сразу через серверную нормализацию.
